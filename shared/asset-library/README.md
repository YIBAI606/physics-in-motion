# 忆白科学动画素材库 v0.1

首批面向热统第三期：同温的金属和木头为什么触感不同。
这是可编辑素材和组件库，不是外部素材链接清单。

## 使用
下载 ZIP 后解压，双击 index.html 离线查看全部素材。SVG 可缩放、改色并由浏览器渲染；剪映不直接识别 SVG 时，用浏览器/矢量软件导出透明 PNG 再导入。动态 SVG 并非视频，本版没有预渲染动效 MP4。

- objects/：金属块、木块、手指。
- science/：热流箭头、统一温标、温度计、理想接触传热模型。
- templates/：接触截面、文献证据卡。
- motion/：可复现的时间函数。
- tokens.json：配色、字号、画幅、安全区和节奏参数。
- manifest.json：逐项来源、状态及科学使用限制。
- reference/、audio/：入库规范，目前没有第三方论文图片或音乐。

## 审美与科学规则
1. 金属和木头使用相同尺寸；材质用中性纹理区分，不能用一冷一暖暗示初始温差。
2. 同温同色，跨镜头固定温标。温度、热流和材料身份分开编码。
3. 接触截面和温度计是组件，不是测量结果。只有接上数据后才可标数值。
4. contact_model.py 采用理想半无限介质、恒物性、完美接触的一维导热模型。参数没有预设为真实人体或木材，正式应用前核对物性来源及有效时间范围。它不能直接预测冷热感受。
5. 引用卡必须填真实出处，不可把占位线条当论文截图。
6. SVG 透明背景；颜色、轮廓和文字均可编辑。字体使用本机回退，不在包中分发字体。
7. 本批图形由程序原创，未混入上传视频、人声、付费素材或第三方原图。本文件不为项目另行设置开源许可证。

## 新素材入库
先填 manifest 条目：唯一 id、类型、相对路径、版本、标签、来源/许可、科学限制、审阅状态；再加入预览页。禁止只存 final2.svg 等无含义文件名。模型、示意、实测数据、论文重绘分别标记。修改共享素材时升级版本，已发布成片保留所用版本。
