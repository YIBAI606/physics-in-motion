# 交付检查表

“不适用”或“未验证”须注明；不要为完成清单勾选未实际做过的检查。

## 科学
- [ ] 核心问题得到回答，关键概念先解释后使用。
- [ ] 公式、数字、单位、坐标轴与图例核对。
- [ ] 假设、适用条件和模型边界明确。
- [ ] 计算结果有独立核验；不把枚举当作动力学。
- [ ] 文献与素材出处可追溯。

## 声音与画面
- [ ] 配音无漏句、重要错读；实际审听。
- [ ] 各段开始、关键数字及结尾与画面对应。
- [ ] 低置信度对齐片段复听，或明确记录尚未确认。
- [ ] BGM 不遮挡人声，收尾自然。
- [ ] 字幕完整、可读，不遮挡关键图形。
- [ ] 制作标签和内部备注已移出观众页面，必要科学说明仍保留。
- [ ] 竖屏如有制作，已单独排版。

## 文件与播放
- [ ] 编码参数检查通过。
- [ ] 全片解码通过，无异常黑屏、闪帧或音轨缺失。
- [ ] 播放、暂停、拖动通过。
- [ ] 交付文件实际下载成功，大小或摘要一致。
- [ ] 电脑审片；设备/软件：
- [ ] 手机审片；设备/软件：
- [ ] 页面状态和文件内容指向同一版本。

## 归档与授权
- [ ] 保留旁白、独立音轨、字幕、数据、源码和制作记录。
- [ ] 源码依赖齐全，有重建命令；可复现声明与实际检查一致。
- [ ] 大文件不提交到内容仓库。
- [ ] 素材使用条件和必要署名核对。
- [ ] 上传目的地和访问范围符合已有授权。
- [ ] 标题、简介、封面与成片内容一致。
