# 抖音第二期第一条：温度一样，能量能差一倍？

45 秒，1080×1920，24 fps，H.264，无音轨。

- douyin-review.mp4：带旁白字幕，适合直接审阅。
- douyin-clean.mp4：不含旁白字幕，保留解释图文，供剪映配音和字幕编辑。
- voiceover.txt：直接复制到剪映的旁白。
- captions.srt：按当前画面节奏排好的字幕；不是对已生成配音的强制对齐。
- render.py：生成源码，依赖 Python/Pillow、FFmpeg/libass、Noto Sans CJK 系统字体。
- timeline.json：逐段时间与旁白。

剪映流程：导入 clean 版 → 使用旁白文本生成 AI 配音 → 导入 SRT 或从实际配音生成字幕 → 检查句子与镜头对应。当前预留 45 秒，不保证不同音色语速都自动吻合；若偏差明显应调整片段时长。

科学范围：相同频率、弱耦合振子在相同温度的平衡平均值比较，激发能以基态为零；12/6 只表示数量比。个体变化用示意柱展示，非数值物理模拟，不表示确定的交换轨迹。平均能量关系不能泛化到不同材料或不同频率振子。
