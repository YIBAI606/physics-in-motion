# 热力学与统计物理

工作定位：从微观到宏观。先启动本系列试制。

概念主线：微观与宏观 → 概率与计数 → 熵与平衡 → 温度 → 分布与系综 → 相变。
结合状态量、功、热与热力学定律，具体顺序随选题调整。

## 首期候选（待确定）
《每一步都能倒放，为什么热量却只往一边流？》

模型候选：两组交换离散能量的爱因斯坦固体。
画面：能量配置、宏观分配的状态数、重复运行及不同系统规模的相对涨落。

科学核查重点：
- 随机交换模型不能直接充当真实微观可逆动力学的证明；标题与模型的关系需要解释。
- 明确交换规则、平衡权重和可达性，不能只凭“状态更多”断言趋近平衡。
- 只有在相应条件成立时才能讨论等概率微观状态。
- 区分能量与温度、单次交换与一段时间内的净热流。
- 比较规模时保持平均能量等条件一致，区分绝对涨落与相对涨落。

原型建议：20–30 秒无旁白片段，同步显示能量交换和宏观分配概率，比较不同规模。
配套短视频候选：《热量会不会自己从冷处流向热处？》

以上均为提案。文献、算法和关键画面尚待核查与实现。
