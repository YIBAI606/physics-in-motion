# 第二期无配音视觉原型

- bilibili-opening.mp4：24 秒，960×540，24 fps。
- douyin-opening.mp4：20 秒，540×960，24 fps。
- 编码：H.264 / yuv420p，faststart，无音轨。
- render.py：逐帧生成程序；依赖 Python、Pillow、FFmpeg 和系统 Noto CJK 字体。

本原型比较相同振子在同一温度下的平均激发能量，能量基准减去零点能。图中 12/6 个振子只用于显示数量比，不对应主片 60/30 的计数实验。E 表示右侧系统的平均激发能量。
横屏扩容段是保持温度的状态比较，不是两个孤立系统在固定总能量下的交换轨迹；扩容过程中不能解释为总能量守恒的封闭过程。振子运动仅作图示，不是物理求解器输出。
正式主片的固定总能量计数实验应另起一段，明确切换条件。

时间为视觉审阅节奏，最终必须按外部 AI 配音重新对齐。尚非完整视频，不含概率分布、推导和结尾。
