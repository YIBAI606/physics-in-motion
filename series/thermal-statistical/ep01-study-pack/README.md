## 最短学习路线
1. 入门：Schroeder 第二章 §2.1—2.4；暂时没有教材时，先读免费论文 Moore–Schroeder（1997）。
2. 动手：完成本包的小系统计数，理解“微观状态等概率”不等于“宏观分配等概率”。
3. 正式语言：Tong §1.2、§1.2.1、§1.2.2。
4. 大系统：回读 Schroeder §2.4，比较绝对涨落与相对涨落。
5. 表达核查：Loverude（2015）；进阶再读 Lebowitz（1993）。
不必先学完全部量子力学，也不必通读所有教材。首轮需要组合计数、概率、对数；温度与大系统近似会用到导数。

## 首期模型卡
研究对象：两组振子，分别有 N_A、N_B 个，每个振子的激发能为 nε，n=0,1,2,…，两组具有相同能量间隔 ε。总激发能固定为 qε。
N 指振子数，不直接等于原子数；三维爱因斯坦固体通常每个原子对应三个振动自由度。固定的零点能不影响这里的配置计数。
假定弱耦合允许能量交换，且对计数可忽略相互作用能；孤立复合系统在指定能量约束下采用微正则等概率分布。计数并未指定交换速率或证明实际系统能遍历所有状态。
一个微观状态是每个有标签振子的占据数列表；本期选择的宏观量是 A 的总量子数 q_A，B 为 q−q_A。

## 核心公式
单系统多重度（星与杠计数）：
Ω(N,q) = C(q+N−1,q)。
固定 q_A 时复合系统的多重度：
W(q_A) = Ω(N_A,q_A) Ω(N_B,q−q_A)。
全部允许状态数：
Σ W(q_A) = Ω(N_A+N_B,q)。
平衡统计概率：
P(q_A) = W(q_A) / Ω(N_A+N_B,q)。

这些关系见 F1、B1；F2 提供系综语境。不能给每个宏观 q_A 相同概率后再声称得到了微正则结果。

## 原创练习（先做，再看答案）
1. N=3、q=2：列出所有占据数列表，核对 Ω。
2. N_A=N_B=3、q=6：列出 q_A=0…6 的 W 与 P，比较“恰好均分”和“两种极端分配合计”。
3. N_A=N_B=1：保持任意总 q，求 P(q_A)。这是否说明仅有左右对称就足以保证中心尖峰？
4. 将 N_A 改为2、N_B改为4，q=6：重新计算峰的位置；为什么不能把所有热平衡都叫能量相等？
5. 令 N_A=N_B=N，比较 N=3、30、300，固定 q=2N。画横轴 q_A/q 的分布。区分“恰好均分的概率”和“偏离一半不超过10%的概率”。
6. 对首期的每个结论标记：模型定义、统计假设、数学结果、还是动力学结论？

## 原创练习参考答案
1. (2,0,0)、(0,2,0)、(0,0,2)、(1,1,0)、(1,0,1)、(0,1,1)，共6种。
2. W 依次为28、63、90、100、90、63、28，总数462。
P 依次约为6.061%、13.636%、19.481%、21.645%、19.481%、13.636%、6.061%。
恰好均分为100/462；两种极端合计56/462。小系统尚未高度集中。
3. 每个 q_A 对应一个状态，P=1/(q+1)，分布平坦。很多自由度带来的组合数量差异至关重要。
4. W 依次为84、112、105、80、50、24、7，总数462，峰在 q_A=1。有限系统的众数和均值不必相同；此例均值为2。
5. 在固定激发能密度 q/(2N) 下，相对宽度随 N 增大缩小；恰好均分这一离散点的概率并不趋近1。
进阶校验：令 M=N_A+N_B，均值 E[q_A]=q N_A/M；方差 Var(q_A)=q N_A N_B(M+q)/(M²(M+1))。
可由上述组合分布直接求和验证；这些矩与本包数表是独立计算结果，非教材习题答案摘录。

## 常见误解核查
- “均分”是两侧宏观总能量接近，不是每个振子能量相同。
- 对称意味着分布对称，不自动意味着中心占绝对优势。
- 宏观状态数量少，不等于它们等概率。
- 相对涨落缩小，不等于绝对涨落缩小。
- 固定分辨率范围的集中，不等于单个精确分配的概率趋于1。
- 接触后同温，一般不意味着总能量相同。
- 本期的宏观分配不是经典能量均分定理。
- 可访问的状态数与真实动力学所需时间是不同的问题。
- 随机“选一个有能量的振子”再搬能量等规则可能引入偏置；动画中的交换算法需要另行验证平稳分布。
- 本期资料包的计算只验证平衡分布，不是时间演化模拟。
