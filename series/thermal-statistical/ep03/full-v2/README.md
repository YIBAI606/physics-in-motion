# 第三期加长修订版 v0.2

256秒（4分16秒），1920×1080，30fps，无配音。
原审阅版157秒，本版新增99秒及对应旁白，不是整片等比例慢放。

修订内容：
- 清除基础场景自带的旁白文字，底部932—1080px逐帧清空，由SRT独占，避免旧字幕残字。
- 全部旁白最多两行，每行不超过28个字。
- 新增比较条件、手失去热量的方向解释、温标说明、曲线坐标解读、曲线逐步生长、密度/比热的作用及现实接触条件。
- 温度场对比重新播放相同模型时间区间，画面明确标注重播及模型时间，不冒充连续实测。

文件：ep03-v2-review.mp4 带字幕审阅；ep03-v2-clean.mp4 剪映配音底片；voiceover.txt、captions.srt、timeline.json 为新版旁白和预排时间。
代码：render.py 调用 scenes.py、visual_base.py 和 build_ass.py。captions.ass 使用显式1920×1080坐标与42px字高，固定双行字幕位置。依赖 Pillow、NumPy、FFmpeg（含libass）、Noto Sans CJK字体。

科学范围：参数为教学示例，非人体/具体材料实测值；接触模型为半无限介质、恒物性、无接触热阻的一维解析解，无血流和感知模型。温度曲线取皮肤表面下0.15mm，而非界面点。没有添加未核对来源的论文图片。正式定量引用仍需查证物性。

配音流程不变：先审阅视频，再用剪映AI配音。预排字幕不能保证任意音色语速自动同步，配音后需按实际语音调整镜头。
