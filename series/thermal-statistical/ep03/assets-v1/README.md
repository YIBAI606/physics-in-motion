# 忆白 EP03 素材包 v1

主题：摸起来更冷，却让冰融得更快？

打开 index.html 离线浏览；contact-sheet.jpg 为总览。

## 已包含
- 12 项本期新素材，各有可编辑 SVG 和 PNG。主画幅1920×1080；03冰块为透明底。
- 3 项既有原创透明物件：手指、金属块、木块，保留原始尺寸。
- data/model.json 教学模型参数，data/skin-temperature.csv 曲线数据。
- build.py 生成源码（Python、Pillow、Inkscape；物件依赖既有共享素材库）。
- history/sources.json：3 项已核对来源与许可的历史图片链接；download.py 可在允许访问 Wikimedia 的电脑下载。

## 科学与使用边界
- 所有科学图是原创示意或教学模型，不是实拍或实测。
- 参数为示意值，不对应经过核验的具体金属、木材或人体测量。
- 曲线观察深度0.15mm；不得称为界面温度或统一感受器深度。
- 半无限体、一维、常物性、完美接触、不考虑血流。
- 融冰图仅示意摆放，没有伪造融化速度。实际实验须控制初温、材料尺寸、冰的质量与初温、接触和环境条件。
- 原创绘图由本项目程序生成；不擅自给整个项目指定新的开源许可。外部素材依各自许可。
- 未生成AI图片：本批需要精确科学图，结尾微光也由代码完成。
