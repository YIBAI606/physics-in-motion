# 第三期接触传热样片 v0.1

22 秒，原生 1920×1080，30fps，H.264，无配音。

0–3 秒：相同形状的金属与木块，标记相同初始温度。
3–8 秒：手指接触，提出触感差异。
8–22 秒：并排展示皮肤—材料的理想一维温度场，同一温标和空间比例。

本版采用素材库的材质分工、字体、温度色阶规范；场景由 render.py 原生绘制，不是完整第三期，也未包含论文图或配音。

模型：两块半无限、均匀、恒物性介质完美接触，界面温度 Tc=(e1*T1+e2*T2)/(e1+e2)，各侧 T(x,t)=T_initial+(Tc-T_initial)*erfc(x/(2*sqrt(alpha*t)))。不含接触热阻、皮肤血流、受压变形或感觉模型。皮肤初始32°C、材料22°C，热感受率和扩散率仅为教学示例参数，详见 model.json；并非具体金属、木材或人体实测物性。短时模型不支持任意长时间/有限厚度推断。

金属木材外观不编码温度；初始22°C不是接触后的动态读数；箭头只表示方向，不能据粗细比较热流大小。屏幕时间与模型时间比例明确显示于画面。

验收：全片解码、时长/分辨率/帧率检查；抽查材质开场及接触温度场。基础模型的接触两侧温度连续、零温差无传热、同物性界面温度为均值均可解析验证。第三期正式制作前需核对真实物性出处，再确定是否使用数值标注。

运行：Python + Pillow + NumPy + FFmpeg；系统安装 Noto Sans CJK 字体。python render.py
