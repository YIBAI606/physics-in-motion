# 10×10配置计数原型 v0.1

42秒、1280×720画布、无配音、无外部依赖。HTML同时包含动画代码与播放器；这是关键镜头原型，尚非最终MP4。

## 打开
从仓库下载 prototype.html（文件页右上下载原始文件），在现代桌面浏览器中打开；或下载仓库ZIP，进入此目录双击文件。
GitHub文件预览不会执行动画。
点击播放；空格可切换播放/暂停；可拖动进度和重播。

## 时间线
- 0–16秒：三个振子装三份激发能，按3＋6＋1枚举十种占据数配置。
- 16–24秒：两侧各十种配置。
- 24–35秒：固定A，逐一配对B，然后填满十行。
- 35–42秒：100种微观状态归属于宏观结果3｜3。

## 科学检查
程序枚举无重复的10个非负整数三元组，每组总和3；笛卡尔积产生100个唯一六元组，左右各3份、总共6份。
本片只做配置计数，没有展示微正则概率或物理时间演化。
空格位置有标签含义；同一格的能量单位没有身份，不对能量块置换重复计数。

## 验证状态
已用Node VM执行全部1261个30fps采样时间点，检查绘图数值有限；验证模型唯一性和重播/暂停状态。
这是模拟DOM的逻辑测试，不是实际浏览器播放验收。
云端Chromium启动因系统setsockopt权限限制退出，尚未完成截图、字体和真实播放的视觉验收。
AI配音与MP4导出尚未实施。本原型用于检验解释与布局，不意味着选定最终渲染技术栈。
