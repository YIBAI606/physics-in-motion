# 项目立项 v0.1

日期：2026-10-29

## 已确定方向
用代码生成每一帧，制作量子力学、热力学与统计物理两个科普系列。每个系列包含长视频和短视频，不限定教材。先从热统打磨制作流程，再推进量子力学。

风格参考 3Blue1Brown：用视觉建立直觉，让动画参与推理。采用原创脚本、画面和代码，不照搬现有视频。

## 试制目标
- 长视频暂以 8–12 分钟为目标，完成一次完整推理。
- 短视频暂以 45–90 秒为目标，独立讲清一个问题。
- 共用经过验证的模型与数据，分别编排镜头。
- 目标观众暂定为具备高中数学基础、愿意进一步理解物理的观众。

## 第一阶段交付
一期热统长视频、一条相关短视频，以及参考文献、科学核查、旁白、分镜、可复现代码与第一版视觉规范。

## 当前状态
立项及仓库初始化阶段。试播选题仍为提案，未开始模拟、渲染或配音。
混沌与初始条件敏感性选题已取消。

## 待确定
正式系列名称、试播选题、技术栈、画幅、帧率、配音方式、授权许可及发布平台。

## 验收
科学结论有来源；模型与动画一致；模拟可复现；文字公式清晰；长短视频各自具有完整解释。
