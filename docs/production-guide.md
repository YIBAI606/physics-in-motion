# 制作规范 v0.1

## 工作流程
核心问题 → 文献与科学边界 → 关键画面原型 → 旁白与分镜 → 完整动画 → 配音字幕与剪辑 → 核查。

## 画面原则
- 每次移动、变色和投影对应明确含义。
- 先建立问题，再引入公式；保留必要推导。
- 颜色之外辅以标签、线型或形状。
- 量子画面区分真实空间、态空间和概率分布。
- 热统画面区分微观状态、宏观量、单次轨迹与统计平均。
- 标明模拟时间与视频时间的对应方式，不把加速播放误作真实速率。

## 科学与数值核查
- 保存参考文献链接、支持的具体论点及适用条件。
- 记录模型、参数、单位、初始条件、算法、随机种子和依赖版本。
- 针对模型检查守恒量、解析结果或已知极限。
- 需要时检查时间步长、采样数量与数值精度的影响。
- 平衡分布和趋近平衡的动力学分别验证。
- 区分示意动画、数值模拟与真实实验。

## 代码组织
模拟数据与渲染分开。共享组件放在 shared/；每期在对应系列下建立独立目录，保存研究笔记、脚本、分镜、模拟与渲染入口。
实际工具链确定后补充安装、验证和渲染命令。

## 素材与输出
生成数据放在 generated/，渲染文件放在 renders/，两者不进入 Git。
源素材记录出处与许可；正式视频使用独立存储或发行附件。
技术栈和许可证尚未确定，不预置依赖或开放许可。
